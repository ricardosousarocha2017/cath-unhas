# Cath Unhas - Notificações Automáticas via WhatsApp & SMS

Plataforma Web com Notificação Automática sem intervenção manual:
- Disparo automático de WhatsApp e SMS no exato instante em que o cliente confirma o agendamento no site.
- Integração com gateways de envio de mensagens (CallMeBot / Z-API / Twilio).
- Painel Administrativo de Faturamento, Relatórios de Vendas e Controle de Horários.
